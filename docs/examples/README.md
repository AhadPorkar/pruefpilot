# Fictional customer-report examples

`DEMO-report-en.zip` and `DEMO-report-de.zip` were generated by the actual explicit-preview adapter. They demonstrate the package structure using fictional records and evidence. They are not real inspection reports, certificates, electronic signatures or evidence of backend execution.

Extract a copy and open `report.html`. Review the full structured records in `data.json`, the CSV files and the original evidence. To check consistency without extracting:

```bash
python scripts/verify-report.py docs/examples/DEMO-report-en.zip
python scripts/verify-report.py docs/examples/DEMO-report-de.zip
```

A SHA-256 manifest detects changes relative to that manifest. It cannot identify the author or prove that the manifest itself has not been replaced.
